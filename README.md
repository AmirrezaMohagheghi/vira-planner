# ویرا | دستیار برنامه‌ریزی شخصی

ویرا یک دستیار برنامه‌ریزی شخصی فارسی‌زبان است که هدفش کمک به مدیریت واقع‌بینانهٔ زمان، وظایف، تعهدات، یادگیری و اسناد است؛ نه صرفاً نمایش یک فهرست کار.

## وضعیت پروژه

پروژه در مرحلهٔ نمونهٔ اولیه (Prototype) قرار دارد. رابط فعلی شامل فهرست وظایف، تقویم شمسی و ذخیره‌سازی محلی ساده است. این نسخه هنوز محصول حرفه‌ای یا آمادهٔ استفادهٔ روزمرهٔ قابل‌اتکا نیست.

## اصول محصول

- فارسی و راست‌چین (RTL)، تقویم شمسی، ساعت ۲۴ ساعته و هفته از شنبه
- دسکتاپ‌محور در شروع، با امکان توسعهٔ واکنش‌گرا
- Local-first: داده‌های شخصی تا حد ممکن روی دستگاه باقی بمانند
- کارکردهای پایه در حالت آفلاین، بدون نیاز به مدل هوش مصنوعی محلی
- هوش مصنوعی آنلاین و اختیاری؛ شروع با Mistral و معماری چندارائه‌دهنده‌ای
- کلیدهای API فقط در سمت سرور؛ هرگز در کد مرورگر قرار نگیرند
- موتور زمان‌بندی قطعی و قابل‌آزمایش، مستقل از مدل هوش مصنوعی
- برنامه‌ریزی منعطف با حفظ زمان آزاد، استراحت و حاشیهٔ امن
- تغییرات برنامه شفاف، قابل‌مشاهده و تا حد ممکن قابل بازگردانی
- حذف دائمی و عملیات حساس فقط با تأیید کاربر

## نقشهٔ راه سطح بالا

1. تثبیت نیازمندی‌ها، معماری و مدل داده
2. بازسازی هستهٔ وظایف و ذخیره‌سازی امن‌تر
3. برنامهٔ هفتگی ثابت، رویدادهای تکراری و استثناها
4. موتور زمان‌بندی و باززمان‌بندی
5. سیستم اعلان و آلارم صوتی
6. اهداف، عادت‌ها، کتابخانهٔ اسناد و گزارش‌ها
7. backend امن و اتصال اختیاری هوش مصنوعی
8. جست‌وجوی وب کنترل‌شده، پشتیبان‌گیری، آزمون و بهبود تجربهٔ کاربری

## توسعهٔ محلی

در وضعیت فعلی پروژه یک وب‌اپ ساده است و برای اجرای نمونهٔ اولیه می‌توان فایل `index.html` را با Live Server در VS Code باز کرد. دستورها و وابستگی‌های پروژه پس از تثبیت ابزارهای build و test در این فایل ثبت خواهند شد.

## اصل مهم توسعه

پیش از تغییر ساختار یا مدل داده، داده‌های فعلی کاربر باید حفظ شوند. هر مهاجرت داده باید نسخه‌دار، قابل‌آزمایش و دارای مسیر پشتیبان‌گیری/بازیابی باشد.
